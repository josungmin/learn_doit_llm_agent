# 문라이트를 사용한 논문 요약

이 논문인 **"Attention Is All You Need"**는 기존의 Sequence Transduction 모델들이 주로 사용하던 Recurrent Neural Networks(RNN)나 Convolutional Neural Networks(CNN)의 복잡한 구조를 완전히 배제하고, 오직 **Attention mechanism**에만 의존하는 새로운 네트워크 구조인 **Transformer**를 제안합니다.

### 1. 핵심 동기 및 배경
기존의 RNN 기반 모델은 순차적 계산(sequential computation) 방식 때문에 학습 시 병렬화가 어렵고, 긴 시퀀스에서의 의존성 학습에 한계가 있었습니다. Transformer는 이러한 순차적 계산의 제약을 극복하고, 입력과 출력 시퀀스 간의 전역적 의존성(global dependencies)을 직접적으로 모델링하여 학습 효율성과 성능을 동시에 향상시키는 것을 목표로 합니다.

### 2. 핵심 방법론: Transformer 구조
Transformer는 Encoder-Decoder 구조를 따르며, 핵심 구성 요소는 다음과 같습니다.

*   **Encoder-Decoder Stacks**: Encoder는 6개의 동일한 층(layer)으로 구성되며, 각 층은 Multi-Head Self-Attention과 Position-wise Feed-Forward Network의 두 하위 층으로 이루어집니다. Decoder 또한 6개의 층으로 구성되나, 두 층 사이에 Encoder의 출력에 대해 Attention을 수행하는 세 번째 하위 층이 추가됩니다. 모든 하위 층에는 Residual Connection과 Layer Normalization이 적용됩니다.
*   **Scaled Dot-Product Attention**: Attention 함수는 Query(Q), Key(K), Value(V)를 입력받아 다음과 같이 계산됩니다.
    $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
    여기서 $\sqrt{d_k}$로 나누는 것은 내적값이 커질 때 Softmax 함수의 기울기가 지나치게 작아지는 현상을 방지하기 위한 Scaling 기법입니다.
*   **Multi-Head Attention**: 단일 Attention을 수행하는 대신, Query, Key, Value를 서로 다른 학습 가능한 선형 투영(linear projection)을 통해 $h$개의 공간으로 투영하여 병렬로 Attention을 수행합니다. 이는 모델이 서로 다른 위치의 다양한 표현 부분공간(representation subspaces)에서 정보를 동시에 참조할 수 있게 합니다.
*   **Position-wise Feed-Forward Networks**: 각 위치에 독립적이고 동일하게 적용되는 완전 연결 신경망(Fully connected feed-forward network)으로, 두 번의 선형 변환과 ReLU 활성화 함수로 구성됩니다.
*   **Positional Encoding**: 모델이 순서 정보를 활용할 수 있도록 입력 Embedding에 특정 주기의 사인(sine) 및 코사인(cosine) 함수를 이용한 위치 값을 더해줍니다.

### 3. 주요 장점 및 성능
*   **병렬성 및 효율성**: Recurrent 연산이 없으므로 학습 시 문장 내의 모든 위치를 동시에 처리할 수 있어 병렬화가 매우 용이하며, 연산 복잡도와 경로 길이를 최적화하여 더 짧은 시간에 더 높은 성능을 달성합니다.
*   **성능 우위**: WMT 2014 English-to-German 및 English-to-French 번역 작업에서 기존의 모든 앙상블 모델보다 뛰어난 BLEU 점수를 기록하며 새로운 State-of-the-art를 달성했습니다. 특히, 매우 적은 학습 시간으로도 뛰어난 품질을 보여줍니다.
*   **일반화 능력**: 번역뿐만 아니라 English Constituency Parsing 작업에서도 성공적으로 적용되어 모델의 범용성을 입증했습니다.

### 4. 결론
Transformer는 Sequence Transduction 작업에서 Recurrence를 완전히 제거하고 Attention 만으로 구성된 아키텍처가 매우 효과적임을 증명했습니다. 이는 이후 대규모 언어 모델(LLM) 발전의 근간이 되었으며, 데이터의 효율적인 병렬 처리를 통해 딥러닝 연구의 패러다임을 전환하는 계기가 되었습니다.

# openai gpt-5.6-luna를 사용한 논문 요약

기존의 순환신경망(RNN)과 합성곱신경망(CNN) 기반 시퀀스 모델은 순차적 계산으로 인해 병렬화가 어렵고, 장거리 의존성을 학습하는 데 한계가 있다. 저자들은 순환과 합성곱을 모두 제거하고 자기어텐션만으로 구성된 Transformer를 제안한다. Transformer는 번역 품질을 높이는 동시에 계산의 병렬화와 학습 효율을 크게 개선할 수 있음을 실험으로 보였다.

### 1. 핵심 동기 및 배경
- RNN·LSTM 기반 모델은 입력과 출력의 각 위치를 순차적으로 계산하므로 학습 병렬화가 어렵고, 긴 문장에서는 학습 시간이 증가한다.
- CNN은 병렬 계산이 가능하지만 멀리 떨어진 토큰 간의 관계를 연결하려면 여러 층이 필요해 장거리 의존성 학습이 복잡해진다.
- 어텐션은 토큰 간 거리에 관계없이 직접 의존성을 모델링할 수 있지만, 기존에는 주로 RNN이나 CNN과 함께 사용되었다.
- 이에 따라 저자들은 모든 위치를 직접 연결하면서도 병렬 계산이 가능한 순수 자기어텐션 구조를 목표로 삼았다.

### 2. 핵심 방법론
- **Transformer 구조**: RNN이나 CNN 없이 인코더와 디코더를 여러 층 쌓고, 각 층을 자기어텐션과 위치별 피드포워드 네트워크로 구성한다.
- **멀티헤드 어텐션**: 하나의 어텐션만 사용하는 대신 여러 개의 어텐션 헤드가 서로 다른 표현 공간과 위치에서 정보를 동시에 학습하도록 한다. 실험에서는 8개 헤드를 사용했다.
- **Scaled Dot-Product Attention**: Query와 Key의 내적을 차원 크기의 제곱근으로 나눈 뒤 softmax를 적용해 Value를 가중합한다. 이를 통해 고차원 내적이 지나치게 커져 학습이 불안정해지는 문제를 완화한다.
- **세 가지 어텐션 활용**:
  - 인코더 자기어텐션: 입력 문장 내부의 모든 위치 관계 학습
  - 디코더 자기어텐션: 이전 출력 위치만 참조하도록 마스킹
  - 인코더-디코더 어텐션: 디코더가 입력 문장 전체를 참조
- **위치 인코딩**: 순환이나 합성곱이 없으므로 사인·코사인 함수 기반 위치 정보를 임베딩에 더해 토큰 순서를 반영한다.
- **학습 안정화 및 일반화**: 잔차 연결, 층 정규화, 드롭아웃, 라벨 스무딩, Adam 옵티마이저와 학습률 워밍업·감쇠 전략을 사용했다.

### 3. 주요 장점 및 성능
- 자기어텐션은 한 층에서 모든 위치를 연결하며 순차 연산 수가 \(O(1)\)이고, 장거리 의존성의 최대 경로 길이도 \(O(1)\)이다.
- RNN의 \(O(n)\) 순차 계산을 제거해 학습 과정의 병렬화가 크게 향상되며, CNN보다 장거리 관계를 더 직접적으로 학습한다.
- WMT 2014 영어-독일어 번역에서 **28.4 BLEU**를 기록해 기존 최고 성능보다 2점 이상 향상되었고, 앙상블 모델까지 능가했다.
- 영어-프랑스어 번역에서는 단일 모델 기준 **41.8 BLEU**로 당시 최고 수준을 달성했으며, 8개의 P100 GPU에서 약 3.5일 만에 학습했다.
- 기존 경쟁 모델보다 훨씬 적은 학습 비용으로 높은 성능을 달성했다.
- 영어 구문 분석에도 적용해 제한된 WSJ 데이터만으로 91.3 F1, 반지도 학습 환경에서 92.7 F1을 기록하는 등 다른 과제에도 잘 일반화되었다.
- 일부 어텐션 헤드는 장거리 동사-구문 관계나 대명사 지시 관계 등 문법·의미 구조와 관련된 패턴을 학습해 해석 가능성도 보여주었다.
- 다만 기본 자기어텐션의 계산량은 시퀀스 길이에 대해 \(O(n^2d)\)이므로 매우 긴 입력에서는 계산 및 메모리 부담이 발생할 수 있다.

### 4. 결론
Transformer는 순환과 합성곱을 완전히 배제하고 멀티헤드 자기어텐션만으로 시퀀스 변환을 수행한 최초의 주요 모델이다. 이 구조는 높은 번역 품질, 뛰어난 병렬화, 짧은 학습 시간과 낮은 비용을 동시에 달성하며 기존 RNN·CNN 기반 모델의 한계를 극복했다. 저자들은 향후 이미지·음성·영상 등 다른 입력 양식과 긴 시퀀스를 위한 제한적 어텐션, 그리고 더 비순차적인 생성 방법으로의 확장을 제안한다.
